## What Changed

Python extensions can now register a dedicated
`api.register_entry_renderer(custom_type, renderer)` for durable records created
with `ctx.append_entry(...)`. In the product TUI, the renderer receives a
detached copy of the complete stored entry together with the current expanded
state, terminal width, and theme, and can return a bounded component for that
record.

The same entry-renderer path is used for a new append, startup replay, `/resume`,
expansion changes, and `/reload`. Reloading can therefore add, replace, or remove
the live rendering of existing entries without rewriting the session. Missing
renderers, `None` results, invalid results, and renderer failures simply omit the
row while leaving the durable entry intact.

This corrects the earlier behavior that routed durable entries through message
renderers and emitted a fallback diagnostic outside the TUI. Entry renderers are
now independent of `register_message_renderer`, are never invoked in print,
JSON, or RPC modes, and cannot place their rendered output in session JSONL,
provider context, protocol output, or the summary-safe archive.

## Boundaries

- `register_message_renderer` and `send_message` keep their existing, separate
  behavior. An extension may register a message renderer and an entry renderer
  for the same custom type without either registry taking ownership of the
  other.
- Durable custom entries remain non-LLM session data. This slice does not add
  them to provider context, invoke their renderer in tree selectors or exports,
  or create a rendering channel for headless modes.
- Cache-friendly dynamic tool loading, package-update/config realignment, the
  broader editor/component/overlay stack, live tool-render invalidation, richer
  multi-widget UI, and an RPC extension-UI channel remain deferred gaps.
- The post-loop safety net made direct workspace-extension probes opt into
  trusted fixtures; it did not change runtime behavior. The separate extension
  package conformance probe still has untrusted project-local fixtures and was
  intentionally left outside this slice.
