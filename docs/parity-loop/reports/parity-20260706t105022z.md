## What Changed

Extensions can now control the label shown when the product TUI folds model
thinking. A live command or shortcut may call
`ctx.ui.set_hidden_thinking_label(...)` or the Pi-shaped
`ctx.ui.setHiddenThinkingLabel(...)` to replace the folded reasoning placeholder;
calling it with no argument or `None` restores the default `Thinking...` label.
The actual hidden reasoning text remains concealed while folding is enabled.

The behavior is live UI state only. It is routed through the extension UI driver
into the terminal renderer, repaints immediately, and is not archived into
conversation/session history. Headless extension execution keeps Pi RPC semantics:
the helper is available but no-ops instead of mutating a fake UI.
