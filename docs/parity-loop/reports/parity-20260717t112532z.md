## What Changed

Python extension tools can now call the existing `ctx.set_active_tools(...)`
control while they run. When a successful tool invocation only adds
already-registered tools, pipy records those additions at that tool result and
preserves the load point across session resume and provider switches.

For eligible Anthropic Messages models—by default, first-party non-Haiku Claude
4.5+ models—the next request keeps those newly activated definitions out of the
immediate cached tool prefix. It marks them for deferred loading and inserts
tool references at the result where they became available, while retaining the
tool's ordinary output. Models without this capability, and changes that remove
or replace tools, continue to receive the complete current tool list.

## Boundaries

- This slice adds Anthropic Messages deferred loading only. OpenAI Responses
  tool search and Kimi Chat Completions deferred-tool request shapes remain
  separate parity work.
- It does not introduce tool discovery, a search algorithm, or a new
  registration API. An extension can activate only tools that are already
  registered, using the existing `ctx.set_active_tools(...)` control.
- Cache-preserving markers are created only by successful extension-tool calls
  that make a purely additive active-set change. Removal, replacement, handler
  failure, and hook-driven changes use the safe full-tool-list behavior.
- Anthropic-compatible endpoints do not opt in automatically. The bounded
  first-party model check applies by default, while an explicit
  `compat.supportsToolReferences` setting can enable or disable support.

## Comprehension Check

<details>
<summary>When does pipy preserve the Anthropic tool-cache prefix after an extension changes the active tools?</summary>

Only when a successful extension-tool invocation adds registered tools without
removing any previously active tool, and the selected Anthropic model supports
tool references. The new definitions are deferred and referenced at that tool
result.

</details>

<details>
<summary>What happens for an older model or a change that replaces a tool?</summary>

Pipy sends the complete current active-tool list without deferred definitions
or tool references. The activation still works; only the cache-preserving
request shape is skipped.

</details>
