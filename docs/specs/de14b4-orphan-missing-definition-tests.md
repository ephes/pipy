# DE14b4 adopted executable acceptance cuts

This is the adopted acceptance matrix. Executed checks, remaining coverage work and source-epoch qualifications are recorded in `docs/evidence/de14b4-orphan-missing-definition.md`; this matrix states the requirements rather than claiming they have all passed.

All success/no-write oracles use genuine Task/Tx-created records and documents. Creation's initial callback may run once; arm action counters and revision baselines afterwards. Typed storage-corruption controls are separately labelled and never described as naturally produced. Use actual Memory and SQLite implementations, real Session tickets/leases, and exact source-pinned helpers. Do not copy a helper's scan limit100 as graph completeness evidence.
