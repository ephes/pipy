## Discriminating additions required by the delivered refresh

- Exercise genuine paused warm/cold construction above before any candidate fitting. In the action observer, count `_fit`, `_fitting_definition`, migration, initial, phase and abort calls separately; the action adds none. Initial creation is not silently included in a zero-callback claim.
- Queue real Session publication and actual commit jobs in both orders, holding before each reaches its line decision. Older→equal/newer publication before action refuses; equal/newer→older before action succeeds. If action commits first, later publication cannot revive the terminal task. Do not force lifecycle flags or treat a queued ticket as a busy witness.
- Bind the same already-captured declaration, then mutate only the external source Task reflectively in a test control; the operation must read its retained captured version, not the mutable source. Do not alter the actual captured generation to manufacture success. Equal signed zeros refuse; include legitimate negative/fractional ordering and preserve Python/JS representability boundaries.
- Generic terminal paths with missing/equal/newer definitions must not call the shared query or consult generation; reserved terminal frames still refuse first. Unknown ID does not create a record. Reentry/off-loop and early exact-ID validation retain B4 ordering; failed/closed/not-open/busy remain ordered at the accepted commit.
- Run retained B4 missing-only tests after the private helper rename and intentional shared REFUSAL wording update; explicitly verify old missing succeeds, old present-older refuses, new missing refuses and new present-older succeeds. Existing source-pinned lease programs remain unchanged unless actual new actor contexts require an additive proof binding.
- Native refusal fixtures must prove the intended comparator/graph branch was reached, not merely any Unsupported exception. Preserve the strengthened observed-page witness and no-write oracle; no mutation-completeness claim.

No blanket Cartesian rerun target is prescribed. Core, isolated broad and comparator scopes are distinct; ordinary whole-repository mypy/Ruff/format runs after all actual overlays and before independent CODE/final effects. The final full/platform/resource/reference gates remain separate from development evidence. Astra refreshes the existing B4 manifest and every existing phase manifest affected by changed source-closure or parent-manifest digests; verify old29 IDs/order, members, Pi pins and edges unchanged while those necessary digests update.
